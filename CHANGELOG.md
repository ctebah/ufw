# Changelog

No formal changelog is maintained yet. Adopters tracking work-in-progress should rely on `git log` and pin a specific commit via `composer.lock`.

A real changelog will start when the project ships its first tagged release. Format will follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versioning will follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
